
#  🔐  Footp-with-multiple-tools
 # 📌 Project Overview
This lab focuses on performing website reconnaissance and information gathering using Kali Linux and various command-line tools. The practical exercise involves analyzing the target domain networkwalks.com to identify publicly available information about its domain registration, DNS records, IP address, web server, and underlying technologies.

During this lab, WHOIS information was examined to identify domain registration details and registrar information. The WhatWeb tool was used to detect technologies and services running on the target website, including Apache, WordPress, Bootstrap, jQuery, and Google Tag Manager. Additionally, the nslookup command was executed to retrieve DNS information and identify the IP address associated with the domain.

The purpose of this practical is to develop hands-on experience with passive reconnaissance techniques, understand how websites expose publicly accessible information, and learn how security professionals gather information during the initial phase of a security assessment.






 # 🎯 Tools Used:
Kali Linux

NSLookup

Target Domain: networkwalks.com
